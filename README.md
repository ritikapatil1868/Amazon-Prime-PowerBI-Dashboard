# Amazon Prime Streaming Insights Dashboard

## 📌 Short Description & Purpose
This project is an interactive dashboard built to analyze Amazon Prime Video’s Movies and TV Shows.  
The goal is to understand content trends, audience preferences, and quality metrics so that streaming platforms can make better business decisions.  
It was created as part of my Almabetter coursework to practice data visualization and storytelling.

## 🛠 Tech Stack
- Power BI (dashboard design and interactive visuals)  
- Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly for EDA)  
- SQL (data preparation and queries)  
- GitHub (version control and portfolio showcase)  

## 📊 Data Source
Dataset provided by **Almabetter classes** during training.  
It includes metadata of Amazon Prime Video titles such as genre, release year, country, IMDb ratings, and votes.

## ✨ Features & Highlights
- **Business Problem & Goal:**  
  Streaming platforms need to know which type of content performs best, which genres attract audiences, and how ratings vary across countries.  
  The dashboard helps answer these questions by providing clear insights into Prime Video’s catalog.

- **Charts Used & Insights:**  
  - **KPIs:** Total Titles, Movies, TV Shows, Average IMDb Rating (quick snapshot of platform size and quality).  
  - **Line Chart:** Release trend over years (shows growth and peak periods).  
  - **Bar Chart:** Top genres with counts (reveals audience preferences).  
  - **Map Chart:** Global distribution of titles (highlights strong and weak regions).  
  - **Scatter Plot:** IMDb Rating vs Votes (shows how audience engagement relates to quality).  

- **Business Impact:**  
  - Identify top performing genres and countries for targeted content investment.  
  - Spot trends in release years to plan future production strategies.  
  - Understand audience engagement patterns to improve recommendations and marketing.  

- **Highlights:**  
  - Interactive slicers for filtering by Type, Release Year, and Country.  
  - Clean design with consistent color palette.  
  - Easy navigation across pages: Overview, Content Analysis, Audience & Quality.
